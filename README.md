# Snake Game Anime Girls — Chrome Extension

A classic Snake game that runs directly in the Chrome browser popup, featuring anime-inspired backgrounds.

**Created by Odesoftami**

## Features

- Classic Snake gameplay.
- Anime-inspired background images.
- Keyboard controls.
- Score tracking.
- Runs directly in the browser popup.
- No account required.

## How to Play

1. Click the extension icon to open the game.
2. Press `Space` to start.
3. Use the arrow keys or `W`, `A`, `S`, `D` to control the snake.
4. Collect food to increase your score.
5. Avoid the walls and your own tail.
6. Press `Space` to restart after game over.

## Installation for Development

1. Clone this repository.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the project directory containing `manifest.json`.
